# Personal Learning Portfolio

เว็บแอปพลิเคชันสำหรับสร้างและจัดเก็บแฟ้มสะสมผลงานการเรียนรู้ (Learning Portfolio) พร้อมบันทึก Reflection และหลักฐานผลงาน (Evidence)

---

## 🌐 วิธีเปิดและเข้าใช้งานเว็บไซต์

- **เวอร์ชัน PHP Server บน AWS EC2 (บันทึกข้อมูลลง Server จริง — แนะนำ):**
  - เปิดใช้งานผ่าน Web Server ที่รองรับ PHP เช่น **Apache บน AWS EC2** หรือรันทดสอบในเครื่องด้วยคำสั่ง:
    ```bash
    php -S localhost:8000
    ```
  - *หมายเหตุ: GitHub Pages รองรับเฉพาะ Static Web จึงไม่สามารถประมวลผล `api.php` เพื่อบันทึกข้อมูลลง Server ได้*
- **เวอร์ชัน Static Preview (ดูหน้าตาเว็บไซต์):**
  - เปิดผ่านลิงก์: https://kawinice.github.io/Personal-Learning-Portfolio/ หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์

## 🧪 วิธีใช้งานและทดสอบระบบ

1. **สร้าง Portfolio:** กรอกข้อมูลในแบบฟอร์มด้านซ้าย (`ชื่อที่ต้องการแสดง`, `What I Enjoy`, `What I've Tried`, `What I'm Curious About`) แล้วกดปุ่ม **สร้าง Portfolio** หรือกด **โหลดข้อมูลตัวอย่าง** เพื่อเริ่มต้นใช้งาน
2. **เพิ่ม Portfolio Item:** เลือก Portfolio ที่ต้องการ แล้วกรอกข้อมูลในส่วน **เพิ่ม Portfolio Item** (`Title`, `Type`, `Date`, `Role`, `Skills`, `Description`, Reflection 4 ช่อง และ `Evidence URL`) จากนั้นกดปุ่ม **บันทึก Item** (หรือกด **ลบ Portfolio** หากต้องการลบ Portfolio)
3. **ตรวจสอบการบันทึกข้อมูล (Persistence):** ลองกด **Refresh** หน้าเว็บ เพื่อยืนยันว่าข้อมูล Portfolio และ Portfolio Item ที่บันทึกลง Server ยังคงอยู่ครบถ้วน
4. **การ Export และ Import ข้อมูล (JSON):**
   - **Export:** ใช้ปุ่ม **แสดง/ซ่อน JSON**, **คัดลอก JSON** หรือ **ดาวน์โหลด my-portfolio.json** เพื่อดู คัดลอก หรือดาวน์โหลดข้อมูล Portfolio ในรูปแบบ JSON
   - **Import Item JSON:** กดปุ่ม **นำเข้า Item JSON** วางข้อความ JSON ที่ได้รับ -> กด **ตรวจสอบข้อมูล JSON** -> เลือก Portfolio ปลายทาง -> ตรวจสอบ/แก้ไข Reflection 4 ช่อง -> กด **บันทึกลง Server**

## 🎮 วิธีทดลองเล่น Booth Challenge (Onsite Activity)

กิจกรรมหน้าบูธของกลุ่มเป็นเกมเล่นสดแนว **“หมูหมากาไก่ 1-2-3 โก! (ฉบับCOMSCI)”** โดยไม่ได้ทำเป็นมินิเกมบนเว็บ แต่เปิดคลิปที่มีรูปภาพตัดต่อเข้ามาให้ผู้เล่นพูดตามรูปที่เห็นหน้างาน และบันทึกข้อมูลกิจกรรมไว้ใน Portfolio:

1. **เริ่มเล่นตามจังหวะ:** เปิดคลิปวิดีโอของเกมที่มีการตัดภาพสัญลักษณ์/รูปภาพธีม COMSCI แทรกเข้ามาตามจังหวะ (เช่น ภาพเกี่ยวกับ `โค้ด / รัน / บั๊ก / ค้าง` หรืออุปกรณ์คอมพิวเตอร์) พร้อมเสียงจังหวะที่ค่อยๆ เร็วขึ้น
2. **พูดตามภาพ:** เมื่อคลิปตัดภาพปรากฏขึ้นมา ผู้เล่นต้องพูดคำศัพท์ให้ตรงกับรูปที่เห็นทันทีตามจังหวะคลิป
3. **เงื่อนไขการผ่านด่าน:** หากพูดผิด พูดช้า หรือหลุดจังหวะ จะต้องเริ่มเล่นรอบนั้นใหม่ (ให้โอกาสแก้ตัวสูงสุด 2 ครั้ง) ผู้ที่พูดถูกต้องครบจนจบคลิปถือว่าผ่าน Challenge
4. **บันทึกเข้า Portfolio:** เมื่อทำ Challenge สำเร็จ ผู้เล่นนำโค้ด JSON ของกิจกรรมนี้ไปกด **นำเข้า Item JSON** บนเว็บไซต์เพื่อบันทึกลง Portfolio ของตัวเองได้

**(Skills):**
- Quick Response & Reflex 
- Focus & Concentration 
- Pattern & Visual Recognition 
- CS Terminology

## ⚙️ ระบบจัดเก็บข้อมูลฝั่ง Server (PHP API)

- **การรับ-ส่งข้อมูล:** เชื่อมต่อผ่าน `api.php` โดยใช้ `GET` เพื่อโหลดข้อมูล และ `POST` เพื่อตรวจสอบและบันทึกข้อมูลลง Server
- **การจัดเก็บไฟล์:** บันทึกข้อมูลลงไฟล์ `../data/portfolios_data.json` นอกโฟลเดอร์สาธารณะของเว็บ พร้อมล็อกไฟล์ขณะเขียน (`LOCK_EX`)
- **การตรวจสอบข้อมูลฝั่ง Server:** ตรวจสอบความครบถ้วนของ Portfolio และ Item, ป้องกัน Item ID ซ้ำใน Portfolio เดียวกัน, บังคับกรอก Reflection ครบ 4 ช่อง (`whatIDid`, `whatILearned`, `challenge`, `nextStep`) และตรวจสอบรูปแบบ URL ของ Evidence
