# Personal Learning Portfolio

เว็บแอปพลิเคชันสำหรับสร้างและจัดเก็บแฟ้มสะสมผลงานการเรียนรู้ (Learning Portfolio) พร้อมบันทึก Reflection และหลักฐานผลงาน (Evidence)

---

## 🌐 วิธีเปิดและเข้าใช้งานเว็บไซต์

* **เวอร์ชัน PHP Server (บันทึกข้อมูลลง Server จริง — แนะนำ):**
  * ต้องเปิดผ่าน Web Server ที่รองรับ PHP เช่น **Apache (บน AWS EC2)** หรือรันทดสอบในเครื่องด้วยคำสั่ง `php -S localhost:8000`
  * *หมายเหตุ: GitHub Pages รองรับเฉพาะ Static Web จึงไม่สามารถประมวลผล `api.php` เพื่อบันทึกข้อมูลลง Server ได้*
* **เวอร์ชัน Static Preview (ดูหน้าตาเว็บไซต์):**
  * เปิดผ่านลิงก์: https://kawinice.github.io/Personal-Learning-Portfolio/ หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์

---

## 📝 ขั้นตอนการใช้งาน

1. **สร้าง Portfolio:** กรอกข้อมูลในแผงด้านซ้ายมือ แล้วกดปุ่ม **สร้าง Portfolio**
2. **เพิ่มรายการผลงาน:** กรอกรายละเอียดในแบบฟอร์ม **เพิ่ม Portfolio Item** (ข้อมูลพื้นฐาน, Skills, Reflection 4 ช่อง และลิงก์ Evidence) แล้วกดบันทึก
3. **ตรวจสอบการบันทึก:** ทดลองกด **Refresh** หน้าเว็บ เพื่อดูว่าข้อมูลยังคงถูกบันทึกอยู่ครบถ้วน
4. **นำเข้า / ส่งออกข้อมูล:** สามารถ **Import / Export** ข้อมูลในรูปแบบไฟล์ JSON เพื่อสำรองข้อมูลหรือแลกเปลี่ยนรายการผลงานได้

---

## ⚙️ ระบบจัดเก็บข้อมูลฝั่ง Server (PHP API)

* **การรับ-ส่งข้อมูล:** เชื่อมต่อผ่าน `api.php` (`GET` และ `POST`) เพื่อโหลดและบันทึกข้อมูลลง Server โดยตรง
* **ความปลอดภัยและโครงสร้างไฟล์:** บันทึกข้อมูลลงไฟล์ `../data/portfolios_data.json` นอกโฟลเดอร์สาธารณะของเว็บ พร้อมระบบตรวจสอบความถูกต้องของข้อมูล (Validation) และป้องกัน Item ID ซ้ำฝั่ง Server
